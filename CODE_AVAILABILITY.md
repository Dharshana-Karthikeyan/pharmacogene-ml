# Code Availability Statement

## For inclusion in the paper (Methods or Data Availability section)

The full pipeline source code, including all data-processing steps, model training and evaluation scripts, SHAP explainability analysis, and semi-supervised self-training implementation, is publicly available at:

**https://github.com/Dharshana-Karthikeyan/pharmacogene-ml**

The repository is released under the MIT License. It includes a complete README with installation instructions, usage examples, and descriptions of all output files. All external data sources used (ClinVar, ClinPGx, Ensembl VEP, UCSC Genome Browser, MyVariant.info) are publicly accessible and queried via REST APIs at runtime — no proprietary data or local reference genome installations are required to reproduce the results.
